Everything a desktop VPN needs, nothing it doesn't

One window, a handful of switches. The heavy lifting happens in the Aether core.

Auto failover

Order the protocols you trust. When a route drops, AetherGui reconnects on the next one without you touching anything.

One-click system proxy

Turn on the Windows system proxy with a checkbox. It's cleared again when you disconnect or close the app.

One local port

SOCKS5 and HTTP on the same port (1819 by default) so browsers, CLIs and other apps just work.

Connect on startup

Launch with Windows and be connected a second later on your last working route.

Live delay check

See round-trip delay through the tunnel, plus an optional activity log when you need to know what's happening.

Open source, no account

No sign-up, no telemetry. Read every line on GitHub. An Android build is released alongside.

20+ routes, including chained ones

Go direct through WARP, or stack a transport in front of Tor or Psiphon when the network fights back.

Up and running in a minute

No installer and no admin rights needed.

  1. Download the zipGrab AetherGui-1.0.4-windows-x64.zip from the latest release.
  2. Unzip and runOpen AetherGui.exe. It's self-contained, so no .NET install is required.
  3. Press ConnectLeave the protocol on Auto, or pick a route. Tick "Set Windows system proxy" to route your whole browser.
